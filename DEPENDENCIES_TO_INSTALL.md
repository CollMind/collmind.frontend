# Dependencies to Install

The following dependencies need to be installed for the Sprint 0 frontend implementation:

```bash
npm install xlsx date-fns
```

## Dependencies

- **xlsx**: Used for exporting error reports in Excel format (Customer Import feature)
- **date-fns**: Used for date formatting in notification components

## Type Definitions

If using TypeScript, you may also need:

```bash
npm install --save-dev @types/xlsx
```

Note: `date-fns` includes its own TypeScript definitions, so no additional types package is needed.
